# Lib Downloader

Консольный загрузчик глав с сайтов семейства Lib и локальный сервер для браузерного расширения.

Загрузчик скачивает главы по ссылке или по списку из CSV, сохраняет изображения манги и тексты ранобэ, при необходимости собирает CBZ-архивы и метаданные (`ComicInfo.xml`, `series.json`). Сервер принимает от расширения список тайтлов, сравнивает его с локальной библиотекой и записывает результат проверки в CSV.

## Установка

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
```

Активация окружения.

Windows (PowerShell):

```powershell
.venv\Scripts\Activate.ps1
```

Linux и macOS:

```bash
source .venv/bin/activate
```

Установка зависимостей (`aiohttp`, `Pillow`, `python-dotenv`, `rich`, `tqdm`):

```bash
pip install -r requirements.txt
```

## Быстрый старт

1. Запустите программу: `python main.py`.
2. В меню выберите `1` (ручная загрузка).
3. Вставьте ссылку на тайтл и ответьте на вопросы. Значения по умолчанию указаны в квадратных скобках, их можно принять нажатием Enter.
4. Главы появятся в папке `downloads/`.

## Запуск

```bash
python main.py               # меню; сервер на 127.0.0.1:8080 поднимается автоматически
python server.py             # только сервер
python log_viewer.py         # окно логов сервера (опрос /logs раз в секунду)
python main.py --log-viewer  # окно логов без меню
```

При старте `main.py` проверяет, свободен ли порт 8080. Если сервер ещё не запущен, он стартует в фоне. При выходе из программы фоновый сервер останавливается.

## Режимы работы

```
Выберите режим:
  1. Ручная загрузка (URL)
  2. Пакетное обновление из CSV
  3. Логи сервера (real-time)
  4. Остановить сервер
  5. Выход
```

Ввод: `Ваш выбор [1-5, по умолчанию 1]`.

### 1. Ручная загрузка

Вопросы задаются в таком порядке.

| Вопрос | Пояснение |
|--------|-----------|
| `Ссылка на мангу` | по домену определяется сайт и адрес его API |
| `Токен` | можно пропустить (Enter), см. [Токен авторизации](#токен-авторизации) |
| `Начальный индекс главы`, `Конечный индекс главы` | диапазон по индексу главы в API (это не номер главы) |
| `Дополнительные главы` | номера вроде `0.5`, `10.1` через запятую; Enter — пропустить |
| `Название манги` | переопределяет название папки тайтла; Enter — по умолчанию |
| `Макс. глав одновременно` | по умолчанию 1 |
| `Макс. изображений одновременно` | по умолчанию 5 |
| `Задержка между запросами (сек)` | по умолчанию 0.5 |
| `Директория для загрузки` | по умолчанию `downloads` |
| `Собирать CBZ архивы (y/n)` | по умолчанию `n` |
| `Создавать метаданные (ComicInfo) (y/n)` | по умолчанию `n` |
| `Формат текстовых глав` | только для RanobeLib, см. [Текстовые главы RanobeLib](#текстовые-главы-ranobelib) |

### 2. Пакетное обновление из CSV

Берёт файл `chapter_checker_log.csv` из текущей рабочей директории и догружает недостающие главы. Формат файла описан в разделе [Формат CSV](#формат-csv).

Вопросы:

1. `Выберите источник API`: 1 — MangaLib (`mangalib.me`), 2 — SlashLib (`v2.shlib.life`), 3 — RanobeLib (`ranobelib.me`), 4 — HentaiLib (`hentailib.me`). По умолчанию 1.
2. `Токен`.
3. Те же настройки загрузки, что и в ручном режиме, кроме названия тайтла.

Тайтлы обрабатываются по очереди.

### 3. Логи сервера

Открывает отдельное окно `log_viewer.py`, которое опрашивает `/logs` раз в секунду.

### 4. Остановить сервер

Останавливает фоновый сервер, запущенный из `main.py`.

### 5. Выход

Завершает программу.

## Работа с расширением

Полный цикл обновления библиотеки:

1. Запустите `python main.py`. Сервер поднимется на порту 8080.
2. Откройте страницу с тайтлами на сайте, соберите их через расширение и отправьте на сервер.
3. Сервер сравнит список с локальной библиотекой (или только запросит главы с сайта, в зависимости от режима проверки) и запишет результат в `chapter_checker_log.csv` в рабочей директории.
4. В меню `main.py` выберите режим `2`. Недостающие главы будут скачаны.

Запускайте `main.py` из той папки, где сервер должен создавать `chapter_checker_log.csv`: пакетный режим читает файл из текущей рабочей директории.

Установка и использование расширения описаны в [install_ext.md](install_ext.md).

## Токен авторизации

Токен нужен для доступа к части контента. Подсказки в меню берутся из `sites.py`:

- MangaLib — токен для 18+ контента;
- RanobeLib — текстовые главы без изображений, токен для 18+ контента;
- SlashLib и HentaiLib — требуется Bearer-токен.

У сайтов токены разные: используйте токен того сайта, с которым работаете.

Токен можно вставить на вопрос `Токен` в меню или в поле `Токен` окна расширения. Префикс `Bearer ` добавлять не нужно.

Как получить токен вручную:

1. Откройте сайт и войдите в аккаунт.
2. Откройте DevTools (F12) и перейдите на вкладку **Application**.
3. Слева выберите **Local Storage**, затем домен сайта.
4. Найдите ключ `auth`. Его значение — JSON, токен лежит в поле `access_token` объекта `token`.

## Текстовые главы RanobeLib

Для `ranobelib.me` последним вопросом идёт формат текстовых глав:

```
Формат текстовых глав [1 — оба файла (по умолчанию), 2 — только TXT, 3 — только HTML]:
```

| Выбор | Результат |
|-------|-----------|
| `1` | `chapter.html` и `chapter.txt` |
| `2` | только `chapter.txt` |
| `3` | только `chapter.html` |

Файлы создаются в папке главы `Volume NN/Chapter X/`.

## Структура папок загрузки

Главы сохраняются в `downloads/` (путь задаётся вопросом `Директория для загрузки`). Имя папки тайтла берётся из данных серии или из переопределённого названия.

```
downloads/<тайтл>/
├── series.json          # при включённых метаданных
├── ComicInfo.xml        # метаданные серии, при включённых метаданных
├── cover.jpg            # обложка серии
└── Volume NN/
    ├── ComicInfo.xml    # метаданные тома, при включённых метаданных
    └── Chapter X/
        └── файлы главы
```

Номера тома и главы форматируются как `Volume NN` (двузначный номер) и `Chapter X`.

Если включён пункт `Собирать CBZ архивы`:

- каждая глава пакуется в `Chapter X.cbz` внутри папки тома;
- вся папка тайтла упаковывается в `downloads/<тайтл>.zip`;
- `series.json` и `ComicInfo.xml` попадают внутрь архива.

## Формат CSV

Сервер записывает `chapter_checker_log.csv` в текущую рабочую директорию. Кодировка UTF-8 с BOM, разделитель `;`.

Заголовок:

```csv
TIME;SLUG;DOMAIN;MODE;STATUS;LOCAL;SERVER;MISSING_COUNT;MISSING
```

| Колонка | Содержимое |
|---------|------------|
| `TIME` | время записи, формат `%Y-%m-%d_%H-%M-%S` |
| `SLUG` | slug тайтла |
| `DOMAIN` | домен сайта |
| `MODE` | `CHECK_LOCAL` или `ONLY_SERVER` |
| `STATUS` | статус проверки |
| `LOCAL` | число глав в локальной библиотеке |
| `SERVER` | число глав на сайте |
| `MISSING_COUNT` | число недостающих глав |
| `MISSING` | недостающие главы в виде `index:volume:number` через запятую |

Пример значения `MISSING`: `46:4:12, 47:4:13`.

Пакетный режим читает из строки колонки `SLUG` и `MISSING`, берёт из `MISSING` индексы глав и догружает их. Если `MISSING` пуст, используются колонки старого формата `СТАТУС` и `ПРОПУЩЕННЫЕ_ГЛАВЫ`. Строки без `SLUG` или без распознанных индексов пропускаются.

## Интерфейс

Если установлен `rich` и вывод идёт в терминал, включается интерфейс с общим баром по главам, отдельными барами глав и итоговой таблицей. Завершённые главы остаются в списке со статусом 100 %.

Классический вывод можно включить принудительно.

Windows (PowerShell):

```powershell
$env:LIB_DOWNLOADER_UI="console"
python main.py
```

Linux и macOS:

```bash
LIB_DOWNLOADER_UI=console python main.py
```

## Сервер

Сервер слушает `127.0.0.1:8080`.

| Маршрут | Назначение |
|---------|------------|
| `POST /check` | принимает список slug и режим проверки; возвращает статусы по тайтлам и записывает результат в `chapter_checker_log.csv` |
| `GET /logs` | журнал сервера |
| `GET /logs/ws` | журнал через WebSocket |

## Сборка exe

Пуш тега `v*` запускает `.github/workflows/build.yml`. Workflow собирает PyInstaller one-file бинарники на Python 3.10:

- `MangaLibDownloader-Windows.exe`;
- `MangaLibDownloader-Linux`;
- `MangaLibDownloader-macOS`.

Отдельная задача упаковывает расширение в `extension.zip`. Все четыре файла прикладываются к релизу по тегу.

## Структура проекта

```
main.py            # меню, диалоги настроек, пакетный режим, запуск сервера
server.py          # локальный сервер :8080, маршруты /check, /logs, /logs/ws
downloader.py      # загрузка глав и изображений, текст, CBZ, метаданные
api_client.py      # клиент API, пул глав, повторы при ограничении запросов
sites.py           # реестр сайтов: домены, API, хосты изображений, подсказки токена
reporting.py       # Reporter, ConsoleReporter, выбор интерфейса
reporting_rich.py  # RichReporter: бары, панели, итоговая таблица
csv_contract.py    # формат CSV: заголовок, разбор и запись строк
api_parsing.py     # разбор ответов API
naming.py          # имена папок и файлов
text_render.py     # шаблоны chapter.html и chapter.txt
config.py          # Config и значения по умолчанию
models.py          # модели данных
metadata.py        # ComicInfo.xml и series.json
utils.py           # утилиты, настройка UTF-8 консоли
tests/             # pytest, без сети
extension/         # расширение Chrome (Manifest V3)
```

Примечание: Этот инструмент предназначен только для образовательных целей. Пожалуйста, уважайте авторские права и условия использования MangaLib.
