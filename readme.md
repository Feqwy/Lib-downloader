# MangaLib Downloader

Асинхронный загрузчик манги с Lib-сайтов (MangaLib, SlashLib, HentaiLib и RanobeLib) с автоматической проверкой обновлений и генерацией метаданных для Komga/Mylar.


## Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/Feqwy/Lib-downloader.git
cd Lib-downloader
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

**Зависимости:**
- `aiohttp>=3.9.0` — асинхронный HTTP-клиент и веб-сервер
- `Pillow>=10.0.0` — обработка изображений (конвертация GIF→PNG)
- `python-dotenv>=1.0.0` — загрузка переменных окружения
- `tqdm>=4.66.0` — отображение прогресса загрузки

## Запуск

### Быстрый запуск (Windows)

```bash
run.bat
```

### Ручной запуск

```bash
python main.py
```

### Запуск только сервера

```bash
python server.py
```

## Использование

### Основной интерфейс

После запуска приложение предлагает меню:

```
╔══════════════════════════════════════════╗
║         MangaLib Downloader v1.0         ║
╚══════════════════════════════════════════╝

Выберите режим:
  1. Ручная загрузка (URL)
  2. Пакетное обновление из CSV
  3. Логи сервера (real-time)
  4. Остановить сервер
  5. Выход
```

### Режим 1: Ручная загрузка

1. Введите URL манги (например, `https://mangalib.me/solo-leveling`)
2. Укажите диапазон глав (начальный и конечный индекс)
3. При необходимости добавьте дополнительные главы
4. Настройте параметры:
   - Макс. глав одновременно (по умолчанию: 1)
   - Макс. изображений одновременно (по умолчанию: 5)
   - Задержка между запросами (по умолчанию: 0.5 сек)
   - Директория для загрузки (по умолчанию: `downloads`)
   - Собирать CBZ архивы (y/n)
   - Создавать метаданные ComicInfo (y/n)

### Режим 2: Пакетное обновление из CSV

Автоматическая загрузка недостающих глав из CSV-файла `chapter_checker_log.csv`.

**Формат CSV:**
```csv
TIME;SLUG;DOMAIN;MODE;STATUS;LOCAL;SERVER;MISSING_COUNT;MISSING
2025-01-15_14-30-00;solo-leveling;mangalib.me;CHECK_LOCAL;Не хватает 3;45;48;3;46:4:12, 47:4:13, 48:4:14
```

**Параметры пакетной загрузки:**
- Выбор источника API (MangaLib/SlashLib/RanobeLib/HentaiLib)
- Макс. глав одновременно
- Макс. изображений одновременно
- Задержка между запросами
- Опции CBZ и метаданных

### Режим 3: Логи сервера

Открывает отдельное окно с логами сервера в реальном времени.

### Поддерживаемые источники

| Источник | Домен | Токен | Тип контента |
|----------|-------|-------|--------------|
| MangaLib | mangalib.me | **Требуется для 18+** | Изображения |
| MangaLib | mangalib.org | **Требуется для 18+** | Изображения |
| SlashLib | v2.shlib.life | **Требуется всегда** | Изображения |
| RanobeLib | ranobelib.me | **Требуется для 18+** | Текст (HTML/TXT) |
| HentaiLib | hentailib.me | **Требуется всегда** | Изображения |

### Получение токена для всех сайтов

Токен автоматически извлекается через браузерное расширение:

1. Установите расширение (см. ниже)
2. Откройте любой поддерживаемый сайт (mangalib.me, ranobelib.me, hentailib.me, v2.shlib.life)
3. В расширении нажмите **«Взять»** — токен будет извлечён из сетевого запроса
4. Или введите токен вручную (можно получить через DevTools → Network → запрос к API)

**Примечание:** Токен требуется только для доступа к контенту 18+. Для обычного контента токен не обязателен.

## Браузерное расширение

Расширение для Chrome/Edge автоматизирует сбор slug'ов тайтлов и отправку их на локальный сервер для проверки.

### Установка расширения

1. Откройте `chrome://extensions/`
2. Включите **«Режим разработчика»**
3. Нажмите **«Загрузить распакованное расширение»**
4. Выберите папку `extension/` из проекта

**Подробная инструкция:** [install_ext.md](install_ext.md)

### Использование расширения

1. Перейдите на поддерживаемый сайт (mangalib.me, v2.shlib.life, и т.д.)
2. Откройте расширение через иконку пазла
3. Нажмите **«Старт»** для сбора slug'ов
5. После окончания сбора нажмите **«Отправить на сервер»**

### Режимы работы расширения

| Режим | Описание |
|-------|----------|
| **Server Only** | Проверка только серверных данных |
| **Check Local** | Сравнение с локальными файлами (требуется путь к библиотеке) |

### Интерфейс расширения

- **Статус сервера** — индикатор подключения к локальному серверу
- **Сбор slug'ов** — счётчик собранных тайтлов
- **Настройки** — URL сервера, домен, режим, токен
- **Результаты** — таблица с статусами тайтлов (OK/Не хватает/Ошибка)

## Обработка ошибок

| Ошибка | Причина | Решение |
|--------|---------|---------|
| `429 Too Many Requests` | Превышен лимит запросов | Автоматическая задержка (3-25 сек) |
| `403 Forbidden` | Требуется авторизация | Проверьте токен для SlashLib/HentaiLib |
| `404 Not Found` | Тайтл не найден | Проверьте slug или URL |
| `Empty response` | Пустой ответ от сервера | Автоматический повтор (до 10 раз) |

## Переменные окружения

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `OUTPUT_DIR` | Директория загрузок | `downloads` |
| `MAX_CONCURRENT_CHAPTERS` | Макс. параллельных глав | `3` |
| `MAX_CONCURRENT_IMAGES` | Макс. параллельных изображений | `8` |
| `REQUEST_DELAY` | Задержка между запросами (сек) | `0.03` |
| `FALLBACK_VOLUME_RANGE` | Диапазон перебора томов | `1-15` |
