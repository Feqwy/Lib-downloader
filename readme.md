# MangaLib Downloader v1.0

Асинхронный загрузчик манги с **Lib-сайтов** (MangaLib, SlashLib, HentaiLib и RanobeLib) с автоматической проверкой обновлений и генерацией метаданных для Komga/Mylar.

## Особенности

- **Автоматический запуск сервера** — сервер запускается в фоне при старте
- **Пакетная загрузка** — скачивание недостающих глав из CSV
- **Удобный интерфейс** — меню с навигацией
- **Метаданные** — ComicInfo.xml для совместимости с Komga/Mylar
- **CBZ архивы** — автоматическая упаковка глав

## Быстрый старт

### Вариант 1: Готовый .exe (Windows)

Скачайте последнюю версию со [страницы релизов](https://github.com/Feqwy/Lib-downloader/releases) и запустите `MangaLibDownloader.exe`.

### Вариант 2: Запуск из исходников

```bash
# Установите зависимости
pip install -r requirements.txt

# Запустите
python main.py
```

Или используйте `run.bat` для автоматического запуска.

### Установка расширения (для пакетной проверки)

Для автоматической проверки недостающих глав установите браузерное расширение:

1. Скачайте `extension.zip` со [страницы релизов](https://github.com/Feqwy/Lib-downloader/releases)
2. Следуйте [инструкции по установке](install_ext.md)

## Использование

### Главное меню

```
╔══════════════════════════════════════════╗
║         MangaLib Downloader v1.0         ║
╚══════════════════════════════════════════╝

Выберите режим:
  1. Ручная загрузка (URL)
  2. Пакетное обновление из CSV
  3. Логи сервера (real-time)
  4. Остановить сервер
  5. Выход
```

### 1. Ручная загрузка

1. Выберите режим **1**
2. Введите ссылку на мангу (например: `https://mangalib.me/ru/manga/227849`)
3. Укажите диапазон глав
4. Настройте параметры:
   - Макс. глав одновременно (по умолчанию 1)
   - Макс. изображений одновременно (по умолчанию 5)
   - Задержка между запросами (по умолчанию 0.5 сек)
   - CBZ архивы (y/n)
   - Метаданные ComicInfo (y/n)

### 2. Пакетное обновление из CSV

1. Запустите сервер (автоматически при старте)
2. В браузере откройте расширение, укажите путь к библиотеке и нажмите **«Проверка локально»**
3. Сервер создаст файл `chapter_checker_log.csv` со списком недостающих глав
4. Настройте общие параметры (API, лимиты, опции)
5. Все тайтлы из CSV загрузятся по очереди

### 3. Логи сервера

Открывает отдельное консольное окно с логами сервера в реальном времени. Удобно для отслеживания запросов от расширения.

### 4. Остановить сервер

Принудительно останавливает фоновый сервер.

## Поддерживаемые источники

| Источник | URL | Требуется токен |
|----------|-----|-----------------|
| **MangaLib** | mangalib.me | Нет |
| **SlashLib** | v2.shlib.life | Да (Bearer Token) |
| **HentaiLib** | hentailib.me | Да (Bearer Token) |
| **RanobeLib** | ranobelib.me | Нет |

### Получение токена для SlashLib и HentaiLib

1. Откройте расширение в браузере
2. Зайдите на `v2.shlib.life` или `hentailib.me`
3. Скопируйте Bearer Token из расширения
4. Вставьте токен при выборе SlashLib/HentaiLib в настройках

## Формат вывода

```
downloads/
├── <Название манги>/
│   ├── cover.jpg (обложка)
│   ├── series.json (метаданные)
│   ├── ComicInfo.xml (метаданные)
│   ├── Volume 01/
│   │   ├── Chapter 1/
│   │   │   ├── 001.jpg
│   │   │   ├── 002.jpg
│   │   │   └── ...
│   │   └── Chapter 2/
│   └── Volume 02/
└── ...
```

**Или CBZ архивы** (если включена опция):
```
downloads/
└── <Название манги>.cbz
    ├── Volume 01/
    │   ├── Chapter 1.cbz
    │   └── Chapter 2.cbz
    └── Volume 02/
```

Каждый `.cbz` содержит:
- Изображения страниц (авто-конвертация GIF → PNG)
- `ComicInfo.xml` — метаданные (название, серия, номер, переводчики)

## Настройки

### Параметры загрузки

| Параметр | По умолчанию | Описание |
|----------|--------------|----------|
| Макс. глав одновременно | 1 | Количество глав, загружаемых параллельно |
| Макс. изображений одновременно | 5 | Количество страниц, скачиваемых параллельно |
| Задержка между запросами | 0.5 сек | Пауза между запросами к API (избегайте 429) |
| CBZ архивы | n | Упаковывать главы в CBZ |
| Метаданные | n | Создавать ComicInfo.xml и series.json |

## Troubleshooting

### Ошибка 429 (Too Many Requests)

**Причина:** Превышен лимит запросов к API

**Решение:**
- Увеличьте «Задержку между запросами» в настройках
- Уменьшите «Макс. изображений одновременно»

### Ошибка 403 (Forbidden)

**Причина:** Истек токен доступа

**Решение:**
- Обновите страницу в браузере
- Скопируйте новый токен из расширения

### Сервер не запускается

**Причина:** Порт 8080 занят другим приложением

**Решение:**
- Закройте другие приложения, использующие порт 8080
- Или используйте 4 пункт для остановки сервера и перезапустите приложение

### Логи не отображаются

**Решение:**
- Убедитесь, что сервер запущен (пункт 3 открывает логи в отдельном окне)
- Проверьте, что порт 8080 не занят другим приложением
