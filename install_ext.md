# Инструкция по установке расширения

## Установка из релиза (рекомендуется)

1. **Скачайте расширение**
   * Откройте [страницу релизов](https://github.com/Feqwy/Lib-downloader/releases)
   * Скачайте файл `extension.zip` из последнего релиза

2. **Распакуйте архив**
   * Распакуйте содержимое `extension.zip`
   * **Важно:** Не удаляйте и не перемещайте папку расширения после установки

3. **Откройте настройки расширений**
   * В адресной строке браузера введите: `chrome://extensions/`

4. **Включите режим разработчика**
   * В правом верхнем углу найдите переключатель **Режим разработчика (Developer mode)**
   * Включите его

5. **Загрузите расширение**
   * Нажмите кнопку **Загрузить распакованное расширение (Load unpacked)**
   * Выберите папку, в которую распаковали файлы на шаге 2

## Проверка установки

Если всё сделано правильно:
* В списке расширений появится **Lib Downloader**
* Нажмите на иконку пазла в браузере
* Найдите и закрепите расширение для быстрого доступа
* При нажатии на иконку должно открыться окно с вводом пути к библиотеке

## Обновление расширения

При выходе новой версии:
1. Скачайте новый `extension.zip` из релиза
2. Замените файлы в папке расширения
3. В браузере на странице `chrome://extensions/` нажмите кнопку обновления ↻ рядом с расширением
