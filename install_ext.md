# Расширение Lib Downloader

Расширение Chrome (Manifest V3). Собирает slug тайтлов на страницах поддерживаемых сайтов и отправляет их на локальный сервер загрузчика. Сервер проверяет тайтлы и возвращает статусы, которые расширение показывает в окне.

## Быстрый порядок действий

1. Установите расширение из папки `extension/` (раздел «Установка»).
2. Запустите `python main.py`: вместе с меню поднимется сервер на порту 8080.
3. Откройте страницу тайтлов на сайте, нажмите иконку расширения и `Начать сбор`.
4. Проверьте настройки и нажмите `Отправить на сервер`.
5. Результат появится в окне расширения и в файле `chapter_checker_log.csv`.

## Установка

1. Откройте `chrome://extensions/`.
2. Включите **Режим разработчика**.
3. Нажмите **Загрузить распакованное расширение**.
4. Выберите папку `extension/` из проекта.

Подходит для Chrome и Chromium-браузеров с поддержкой Manifest V3.

Если расширение уже было установлено из другой папки, отключите или удалите старую копию, чтобы работала только одна.

## Подготовка: запуск сервера

```bash
python main.py
```

При старте `main.py` поднимает сервер на `127.0.0.1:8080`, если он ещё не запущен. Только сервер можно запустить командой:

```bash
python server.py
```

В настройках расширения поле `Сервер` по умолчанию содержит `http://localhost:8080`. Расширение опрашивает сервер каждые 10 секунд и показывает состояние `Онлайн` или `Офлайн`.

## Использование

1. Откройте страницу с тайтлами на поддерживаемом сайте. Домен в настройках подставляется из адреса вкладки.
2. Нажмите на иконку расширения.
3. Нажмите `Начать сбор`. Счётчик `Найдено` показывает число собранных slug.
4. Проверьте настройки.
5. Нажмите `Отправить на сервер`.

Кнопка `Стоп` останавливает сбор, кнопка сброса очищает собранный список. Кнопка отправки активна, когда собран хотя бы один slug.

Окно расширения (popup) содержит:

- строку статуса и счётчик найденных slug;
- строку состояния сервера;
- кнопки `Начать сбор`, `Стоп` и кнопку сброса;
- сворачиваемый блок настроек;
- кнопку `Отправить на сервер`;
- блок результатов.

## Настройки

| Поле | Назначение |
|------|------------|
| `Сервер` | адрес локального сервера, по умолчанию `http://localhost:8080` |
| `Домен` | сайт, к которому относится список: `mangalib.me`, `mangalib.org`, `v2.shlib.life`, `ranobelib.me`, `hentailib.me` |
| `Режим проверки` | `Только сервер` или `Проверка локально` |
| `Путь к папке` | путь к локальной библиотеке; показывается в режиме `Проверка локально` |
| `Токен` | токен авторизации для 18+ контента |

Режимы проверки:

- `Только сервер` — локальная папка не учитывается, сервер возвращает данные по главам на сайте;
- `Проверка локально` — сервер дополнительно сравнивает главы с локальной библиотекой по указанному пути.

## Токен

Поле `Токен` показывается для всех поддерживаемых доменов. Токен можно вставить вручную. У сайтов токены разные, поэтому используйте токен того сайта, с которым работаете. Как получить токен, описано в [readme.md](readme.md), раздел «Токен авторизации».

Кнопка `Взять` подставляет токен, перехваченный из заголовка `Authorization` в запросах к API сайта. Перехваченное значение хранится в хранилище расширения. Если токена ещё нет, расширение перезагружает вкладку и ждёт захвата до 10 секунд.

При отправке префикс `Bearer ` добавляется автоматически, если его нет.

## Результаты

После ответа сервера под настройками появляется блок `Результаты`:

- сводка `Всего`, `OK`, `Отсутствует`, `Ошибки`;
- список тайтлов с локальным и серверным числом глав и перечнем отсутствующих глав.

Кнопка очистки в заголовке блока убирает результаты. Сервер также записывает результат проверки в `chapter_checker_log.csv`; этот файл читает пакетный режим `main.py` (пункт меню 2).

## Поддерживаемые сайты

Сбор slug работает на страницах:

- `mangalib.me`
- `mangalib.org`
- `v2.shlib.life`
- `ranobelib.me`
- `hentailib.me`

Доступ расширения задан в `host_permissions`: домены сайтов, их API-хосты (`hapi.hentaicdn.org`, `api.cdnlibs.org`, `api.imglib.info`) и локальный сервер `http://localhost:8080`.

Разрешения расширения: `storage`, `activeTab`, `scripting`, `webRequest`. Сбор выполняет content script, запускаемый на страницах сайтов; заголовок `Authorization` в запросах к API перехватывает service worker.

## Обновление расширения

После изменения файлов в папке `extension/` откройте `chrome://extensions/`, нажмите кнопку обновления рядом с расширением и перезагрузите вкладку сайта.
